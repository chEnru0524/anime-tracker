# 夜番 · 巴哈姆特動畫瘋同步

## 安裝（Chrome / Edge，電腦版）

1. 在 [夜番同步頁](https://chenru0524.github.io/anime-tracker/#/sync) 下載擴充功能 ZIP，解壓縮到固定資料夾。不要選 ZIP 檔本身。
2. Chrome 開啟 `chrome://extensions`；Edge 開啟 `edge://extensions`。
3. 開啟「開發人員模式」，選「載入未封裝項目／載入解壓縮擴充功能」，選取含 `manifest.json` 的資料夾。
4. 點工具列的夜番擴充功能，勾選「啟用偵測與同步」，按「儲存設定」。門檻預設 80%，可改 1–100%。
5. 複製彈出視窗中的擴充功能 ID，貼至夜番「動畫瘋同步」，按「連接並啟用自動同步」。
6. 重新整理已經開啟的動畫瘋分頁。兩個網站須使用同一個瀏覽器設定檔；Codex 內建瀏覽器、Chrome、Edge 的網站資料彼此獨立。

此版本沒有上架擴充功能商店。更新時解壓覆蓋原資料夾，回擴充功能管理頁按重新載入，並重新整理動畫瘋。保留原安裝位置通常可維持 ID；若變更請重新連接。

## 首次匯入

1. 自行在動畫瘋登入，開啟網站的「觀看紀錄」。不要提供帳密給夜番。
2. 點夜番擴充功能 →「讀取動畫瘋觀看紀錄」。它會操作原頁的載入更多（上限 100 次），只讀取顯示的作品、單集、比例及時間；不會刪改動畫瘋紀錄。保持頁面開啟。
3. 開啟夜番同步頁，按立即同步或等待 15 秒。這時只進入待確認清單，尚未改動收藏。
4. 先搜尋動畫並加入「我的動畫」，回同步頁選擇對應作品，核對季度、總集數及對應集數。
5. 展開「設定這部作品日後自動同步」，指定動畫瘋的起訖集數與偏移，按確認配對。例：動畫瘋 73–96 對應夜番 1–24，偏移 -72。
6. 確認匯入各筆；已有配對且達門檻的歷史快照可以一次確認匯入。未達門檻／特別篇需勾選確認並指定集數，或略過。

歷史匯入是目前動畫瘋保留的每部作品最近觀看快照，不是完整終身完播清單。網站顯示「觀看結束」不代表已實際播放 100%；本工具沿用該站的歷史判定供你確認。舊集數明細不提供完整的完播證據，因此不擅自推算所有集數都已看完。下架作品仍可手動配對；沒有可用連結時不製造單集 URL。無法解析觀看時間時不以匯入時間代替。

## 日常觀看

- 在正常動畫瘋播放頁觀看，達到設定門檻後產生同步事件。
- 計算實際、去重的正片播放片段比例；拖曳到片尾、廣告、緩衝與暫停不直接算成看完。播放片段每 15 秒暫存，最近 500 部單集可跨重新整理續算；突然關閉可能損失最後 15 秒未保存片段。
- 認不出播放器或單集時停止記錄，不猜測。可在擴充功能彈出視窗查看偵測狀態。
- 進度採 `max(原進度, 對應集數)`。例如原為 5，實際看完 8，更新為 8；重看 3 不倒退。保留評分、備註及自訂平台，補上「巴哈姆特動畫瘋」。
- 保存達標後的最後觀看時間，每分鐘最多一筆。到達總集數不自動把狀態改為已看完。
- 第一次遇到未配對作品會留在待確認清單；確認作品 ID、集數範圍與偏移後，範圍內的新觀看自動套用。
- 夜番開啟時每 15 秒接收，分頁關閉／瀏覽器暫停背景頁時會延後。事件保存在擴充功能本機佇列，夜番下次開啟再接收。兩邊皆可暫停。
- 佇列最多 5,000 筆，夜番待處理清單最多 10,000 筆，滿時報錯而不靜默丟棄。請定期開啟夜番與處理待確認清單。

## 隱私與安全

- 只需要 `storage`、`activeTab`；content script 僅指定 `ani.gamer.com.tw` 的播放頁與觀看紀錄頁，不在登入頁注入。
- 不申請 cookies、webRequest、debugger、全部網站、downloads 或廣泛 tabs 權限。不攔截請求，不取得串流、DRM 或廣告 Token。
- 不讀取 Cookie。只讀取動畫瘋非憑證的 `ANIME_BP` 續播紀錄中 `videoSn` 與 `breakPoint`，輔助辨識正片。
- 不上傳觀看紀錄至 GitHub Repository、API Provider 或任何伺服器。擴充功能沒有外部 fetch；播放頁與紀錄頁仍由動畫瘋原本程式處理登入 Session。
- 透過 Chrome 原生 `runtime.sendMessage` 傳遞白名單欄位，限定 `https://chenru0524.github.io/anime-tracker/`；其他同帳號 Pages 專案亦被 service worker 拒絕。未使用通用 `window.postMessage` 橋接。
- 擴充功能與網站不同來源的 IndexedDB 不直接共享。夜番在交易提交後才 ACK，失敗不刪佇列；事件 ID 去重，避免重送重複加集數。
- 網站自己的程式具有存取個人紀錄的權限，請只在信任的正式部署使用。其他部署須修改 manifest 與 `trustedTracker` 的固定 allowlist 後自行建置，不能以任意 URL 指定目的地。
- JSON 備份包含同步配對、待確認紀錄與已接收事件 ID；不含擴充功能尚未接收的佇列。備份前先立即同步。還原後自動接收暫停，需重新連接。

## 開發與測試

```sh
npm ci
npm test
npm run build
npx playwright install chromium
npx playwright test
```

`npm run build` 同時建置擴充功能，產生 `extension-dist/` 與網站可下載的 `public/yoru-bahamut-extension.zip`；Vite 將 ZIP 一起部署。只建置擴充功能可執行 `npm run build:extension`。

自動測試用獨立 Chromium profile、合成紀錄與模擬媒體播放，不會使用你的登入 Session。真實頁面研究、可行性與測試邊界見 [RESEARCH.md](https://github.com/chEnru0524/anime-tracker/blob/main/extension/RESEARCH.md)。
